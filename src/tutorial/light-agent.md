# light-agent

These tutorials connect Portal agent authoring to a locally deployed native
`light-agent` runtime and its execution worker.

- [Create codex-personal locally](light-agent/codex-personal.md): register a new
  agent through Task Center, author its coding profile, prepare a personal
  runner, publish its policy in the UI, submit a typed coding request, and verify
  each runtime boundary, including the runner capability check.
